# Reproducibility code

This directory is reserved for the project's reproducibility materials. Future additions may include:

- data preparation and split-generation scripts;
- training and evaluation entry points;
- versioned experiment configurations;
- environment or dependency specifications;
- instructions for obtaining datasets and model checkpoints;
- expected metrics and commands for reproducing reported results.

Large generated datasets, trained checkpoints, caches, private credentials, and machine-specific outputs should remain outside Git or use an appropriate artifact release mechanism.
