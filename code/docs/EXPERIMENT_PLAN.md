# New experiment plan

## Scope decision

All previously reported numbers are treated as exploratory and are excluded
from the new paper. They inform two hypotheses only:

1. pose confidence may trade precision for recall rather than improve every
   metric;
2. scattered missing joints and systematic lower-body loss require separate
   robustness tests.

The central method is a privacy-oriented skeleton sequence classifier with
quality-aware temporal pooling, bidirectional Mamba blocks and train-time frame
masking. A full RGB-audio Fall-Mamba reproduction is a separate multimodal
track; it must not be presented as the same input setting.

## Claim-evidence matrix

| Claim | Evidence | Baselines | Metrics | Status |
|---|---|---|---|---|
| Local and long-range motion are both useful | same-input main comparison | TCN, TE, TCNTE | F1, recall, specificity, AUROC | running: 60-run matrix |
| Bidirectional Mamba improves temporal modeling | remove reverse branch | unidirectional Mamba | F1, event recall | queued after main |
| Temporal attention identifies useful frames | remove attention | mean-pooled Mamba | F1, detection delay | queued after main |
| Quality cues improve missing-observation handling | remove confidence/quality pooling separately and jointly | full, no-quality, no-confidence, neither | clean and corrupted F1 | queued after main |
| Frame masking improves robustness | remove masking and sweep ratio | 0%, 5%, 10%, 15%, 20%, 30% | frame-drop/joint-drop curves | queued after main |
| The method generalizes | subject-independent training and external Le2i test | TCNTE, proposed | per-dataset F1, event recall | queued after main |
| The method is deployable | controlled inference benchmark | TCNTE, proposed | parameters, FLOPs, latency, peak memory | planned |

## Protocol A: TCNTE reproduction

- Datasets: UP-Fall, Le2i and GMDCSA-24 as available.
- Input: 12 non-face COCO joints, `(x,y)` only.
- Window: 1 second, 0.2-second stride; GMDCSA-24 uses 30 frames.
- Model: TCN `[8,16,32]`, Transformer head count 4, one encoder layer.
- Training: batch 64, Adam, learning rate `1e-4`, 100 epochs, weighted
  focal loss with `[1,30]` and gamma 3.
- Report both window- and file/event-level metrics.
- This table is labelled as a reproduction. It is not used to claim a fair
  subject-generalization gain if the paper's video-level split is used.

## Protocol B: primary paper evaluation

- Split by subject whenever IDs exist. For datasets without reliable subject
  IDs, group by source video/scenario and disclose the limitation.
- Reserve validation groups from training groups. Never use test predictions
  for model, epoch or threshold selection.
- Train every model for exactly 100 epochs with no early stopping.
- Evaluate seeds `42`, `3407`, and `2026` on identical folds.
- Primary metric: event/file-level F1 and event recall. Secondary metrics:
  window F1, sensitivity, specificity, AUROC and accuracy.
- Report mean and standard deviation across fold-seed runs and retain every
  per-fold value.

## Dataset roles

- CAUCAFall + GMDCSA-24: frozen 260-video primary subject-independent benchmark (14 subject groups, four folds).
- Le2i: TCNTE reproduction and external/cross-scene test; never used to fit the new primary models.
- UP-Fall: future extension only; not present in the current frozen manifests.
- URFD + Multicam: Fall-Mamba-aligned video-only/missing-modality tests.
- OF-Syn: optional pretraining/augmentation ablation; never a substitute for
  real test data.

## Execution order

1. Audit files, codecs, labels and licences; freeze manifests and checksums.
2. Extract pose tracks once with a pinned detector and tracker.
3. Reproduce TCNTE on one frozen protocol.
4. Run TCN/TE/TCNTE/UniMamba/full method on all four CAUCAFall--GMDCSA-24 folds and seeds `42`, `3407`, and `2026` (running).
5. Run ten paired mechanism variants with seed `42` on all four folds (40 runs).
6. Run robustness on TCNTE and MaskedBiMamba, then external Le2i evaluation.
7. Benchmark speed and memory on the deployment device.
8. Populate result tables from generated JSON/CSV only.

No numeric result is assumed in this plan. All new result cells remain `TBD`
until generated by the frozen code and data manifests.
