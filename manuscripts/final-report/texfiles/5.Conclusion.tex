\section{Conclusion}

This project combines a privacy-oriented edge--cloud prototype with skeleton-based temporal fall detection. The system connects camera input, Raspberry Pi pose extraction, private pose transfer, cloud inference, persistent event handling, and an authenticated dashboard. In the completed CAUCAFall--GMDCSA-24 experiment, the Transformer encoder achieves the highest window F1 ($0.6581\pm0.0766$) and video F1 ($0.7686\pm0.0257$). MaskedBiMamba achieves the highest window precision ($0.6048\pm0.0856$) and the lowest mean offline false-alarm rate ($198.5\pm40.8$~h$^{-1}$), with video F1 $0.7632\pm0.0370$. The rate denominator is evaluated video time, and the metric precedes the deployed alert state machine.

The ablations support the value of bidirectional processing and temporal attention, but they do not show that every element of the complete configuration improves clean-set performance. The strongest evidence for MaskedBiMamba is robustness to missing frames: at 30\% frame loss it retains primary window F1 $0.6276\pm0.0507$, compared with $0.4361\pm0.0669$ for TCNTE, and the advantage persists on external Le2i. Random joint loss and missing lower-body observations remain difficult for both models. Controlled edge latency, bandwidth, power, and recovery measurements are still required before making real-time deployment claims.
