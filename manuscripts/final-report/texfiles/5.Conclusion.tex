\section{Conclusion}

This project delivers MaskedBiMamba and FallGuard as an integrated fall-detection solution. Quality-aware bidirectional temporal modeling achieved the highest window precision among the compared models at the common threshold and preserved 98.1\% of clean window F1 under 30\% frame removal. Attention and bidirectional processing improved matched component comparisons. Raspberry Pi deployment combined approximately 7.7-ms temporal inference with a 20.56-frames/s accelerated video pipeline, persistent local alerts, and successful recovery of all 85 tested cloud records. The result connects a robust temporal classifier to an implemented camera--edge--cloud--user workflow, with continuous-recording calibration and longer deployment evaluation as the next steps.
