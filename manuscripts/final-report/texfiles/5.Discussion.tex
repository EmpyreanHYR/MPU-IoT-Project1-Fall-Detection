\section{Discussion}

MaskedBiMamba's clearest model advantage is stable classification when pose observations are interrupted. The primary frame-loss experiment retained 98.1\% of clean window F1 at 30\% frame removal, and the external Le2i experiment showed the same advantage over TCNTE. Higher precision and fewer unmatched events at the shared threshold complement this robustness. The attention and bidirectionality ablations further support combining relationships across the complete window with forward and backward state-space processing.

The system design makes these model gains available locally. Hailo accelerates the pose stage, while the compact temporal input allows MaskedBiMamba to run on the Pi CPU in approximately 7.7 ms per window. Transactional record storage, identifier-based deduplication, and acknowledgement after cloud commit preserve the event history during interrupted connectivity. The local workspace supports review without a network; the cloud workspace provides durable history after synchronization.

Relative to the proposal, temporal classification moved from the cloud to the Raspberry Pi, and HTTP/SQLite replaced MQTT/PostgreSQL. This implementation meets the objectives of near-camera processing, disconnected inference, deferred event delivery, and user review. The proposed skeleton/geometry fusion developed into a quality-aware bidirectional temporal model evaluated through matched baselines, component ablations, and observation perturbations.

\subsection{Evaluation scope and next steps}

The evidence covers 14 primary subject groups, an external Le2i test, 40 synthetic edge clips, and a ten-minute stability replay. Continuous recordings with varied camera placement and participants are the next evaluation step, alongside validation-set calibration of the complete alert pipeline. Perturbation-specific component ablations can isolate the mechanisms behind frame-loss tolerance; clean-input masking and pooling ablations already identify useful calibration variants. Longer camera sessions, power measurements, and deployment security review will extend the present system measurements. Recovering reliable Le2i participant identities would strengthen person-independent transfer evaluation.
