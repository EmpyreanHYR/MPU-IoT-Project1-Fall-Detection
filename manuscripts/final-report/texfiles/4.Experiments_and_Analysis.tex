\section{Experiments}
\label{sec:experiments}

\subsection{Datasets and evaluation protocol}

The primary experiment uses CAUCAFall~\cite{guerrero2022caucafall,caucafallDatasetV5} and GMDCSA-24~\cite{alam2024gmdcsa,gmdcsaDatasetV2}. CAUCAFall includes ten participants performing five daily activities and five fall types in a home environment; GMDCSA-24 adds four subject groups. Le2i~\cite{charfi2012le2i,yu2025tcnte} provides a separate baseline comparison and an external test of the primary models. Table~\ref{tab:datasets} summarizes the 450 videos. Temporal labels follow the corresponding annotations in OmniFall~\cite{omnifallDataset2026}.

A pretrained YOLOv8s-pose detector~\cite{ultralyticsPose} and BoT-SORT tracker extract the primary person trajectory. The primary comparison uses 12 body joints with normalized coordinates and confidence, giving 36 features per frame. The separate Le2i baseline comparison uses only coordinates, giving 24 features. Both use the window construction defined in Section~\ref{sec:method}.

A window is positive when at least half of its duration overlaps a fall interval and negative when no fall interval overlaps it; intermediate overlaps are excluded. For videos containing a fall, windows starting at or after the end of the final fall transition are excluded. The primary data contain 1,371 positive and 6,498 negative windows; Le2i contains 1,338 positive and 11,312 negative windows.

Four subject-disjoint folds separate the 14 primary participant groups into training, validation, and test partitions, with both datasets represented in every partition. Overlapping windows from one video remain in the same partition. Le2i is held out when training the primary models. The separate Le2i comparison uses three video-grouped folds and a 15\% validation subset.

The edge deployment test uses OmniFall-Synthetic~\cite{omnifallDataset2026}. Before inference, 20 fall and 20 non-fall clips were sampled with a fixed seed from the supplied annotations. These 40 clips contain 3,240 frames. The classifier was selected using primary validation F1 without training or threshold tuning on the synthetic clips. Clip-level prediction uses the maximum window probability at threshold 0.5. Clips without valid pose windows are reported separately as missing outputs.

\subsubsection{Training and comparison models}
All models train for 100 epochs using Adam, learning rate $10^{-4}$, and batch size 64. The focal-loss parameter in Eq.~\eqref{eq:focal_loss} is $\gamma=3$. Class weights are computed from the training partition for the primary comparison and set to $[1,30]$ for the separate Le2i comparison. The primary runs clip the gradient norm at 1.0. Model selection uses validation F1. Primary experiments use seeds 42, 3407, and 2026, giving 12 evaluations per model across four folds; the Le2i comparison uses seed 42. Results are reported as mean and sample standard deviation across folds and seeds.

The comparison includes TCN, Transformer encoder (TE), TCNTE~\cite{yu2025tcnte}, and UniMamba. The TCN has three residual blocks with channels $[8,16,32]$, kernel size 5, dilations $1,2,4$, and dropout 0.2. TE uses a 32-dimensional embedding, learned positions, one four-head encoder layer, and feed-forward width 32. TCNTE applies that encoder to the TCN sequence. UniMamba uses the same 64-dimensional Mamba backbone as MaskedBiMamba with two forward layers and mean pooling. All primary models receive the same windows and pose features.

\subsubsection{Edge deployment configuration}
The edge platform is a 16-GB Raspberry Pi~5 with a Hailo-10H accelerator, Raspberry Pi OS (64-bit), Python 3.13, HailoRT 5.1.1, and ONNX Runtime 1.30.0. The paired timing test compares CPU ONNX and the Hailo compiled YOLOv8s-pose backend at $640\times640$, using four clips replayed twice per backend after five warm-up frames. Both execute the same local temporal classifier. Inference runs inside a network namespace with no external interface or route; an outbound connection check must fail before evaluation.

\subsubsection{Evaluation metrics}

Let $y_i\in\{0,1\}$ be the label of window $i$, with fall as the positive class, and let $p_i=\pi_{i,1}$ be its predicted fall probability. The classification rule is $\hat y_i=\mathbf{1}[p_i\geq\tau]$, where $\tau=0.5$. Using the resulting true positives (TP), true negatives (TN), false positives (FP), and false negatives (FN), we compute
\begin{equation}
\begin{aligned}
\mathrm{Acc} &= \frac{\mathrm{TP}+\mathrm{TN}}{\mathrm{TP}+\mathrm{TN}+\mathrm{FP}+\mathrm{FN}},\\
\mathrm{Prec} &= \frac{\mathrm{TP}}{\mathrm{TP}+\mathrm{FP}},\qquad
\mathrm{Rec}=\frac{\mathrm{TP}}{\mathrm{TP}+\mathrm{FN}},\\
\mathrm{Spec} &= \frac{\mathrm{TN}}{\mathrm{TN}+\mathrm{FP}},\qquad
\mathrm{F1}=\frac{2\mathrm{TP}}{2\mathrm{TP}+\mathrm{FP}+\mathrm{FN}}.
\end{aligned}
\label{eq:metric_confusion}
\end{equation}
Precision measures the reliability of positive predictions, recall measures fall coverage, and specificity measures rejection of non-fall activity. F1 balances precision and recall. A zero denominator gives a score of zero for these metrics.

AUROC measures probability ranking across thresholds. For $N_+$ positive and $N_-$ negative windows,
\begin{equation}
\mathrm{AUROC}=\frac{1}{N_+N_-}
\sum_{i:y_i=1}\sum_{j:y_j=0}\psi(p_i-p_j),
\label{eq:metric_auc}
\end{equation}
where $\psi(d)$ equals 1 for $d>0$, $1/2$ for $d=0$, and 0 otherwise. AUROC is undefined if either class is absent.

A video is positive when at least one of its windows is positive. If $\mathcal W_v$ contains the windows of video $v$, its probability and label are
\begin{equation}
 p_v=\max_{i\in\mathcal W_v}p_i,\qquad
 y_v=\max_{i\in\mathcal W_v}y_i.
\label{eq:metric_video}
\end{equation}
Applying Eq.~\eqref{eq:metric_confusion} to $(y_v,\mathbf{1}[p_v\geq\tau])$ gives video-level metrics.

Event evaluation measures temporal localization. For each video, we merge overlapping or touching positive target windows into reference intervals $\mathcal G_v$ and positive predicted windows into intervals $\mathcal P_v$. Intervals are processed in start-time order; each reference interval is paired with the first unused prediction having positive-duration overlap. Let $\mathcal M_v$ contain these matched pairs. Event recall is
\begin{equation}
 R_{\mathrm{event}}=\frac{\sum_v|\mathcal M_v|}{\sum_v|\mathcal G_v|}.
\label{eq:metric_event}
\end{equation}
For window boundaries $[a_i,b_i]$, the evaluated duration and false-alarm rate are
\begin{equation}
\begin{aligned}
 T_{\mathrm{eval}}&=\frac{1}{3600}\sum_v
 \left(\max_{i\in\mathcal W_v}b_i-\min_{i\in\mathcal W_v}a_i\right),\\
 \mathrm{FA/h}&=\frac{\sum_v\left(|\mathcal P_v|-|\mathcal M_v|\right)}{T_{\mathrm{eval}}}.
\end{aligned}
\label{eq:metric_far}
\end{equation}
The exposure includes the retained portions of both fall and non-fall videos. For a matched pair $(g,h)$ with interval start times $s_g$ and $s_h$, the mean onset offset is
\begin{equation}
 D_{\mathrm{onset}}=\frac{\sum_v\sum_{(g,h)\in\mathcal M_v}(s_h-s_g)}{\sum_v|\mathcal M_v|}.
\label{eq:metric_onset}
\end{equation}
A negative offset denotes an early prediction. This measure describes interval alignment; system latency additionally includes image processing, communication, and alert confirmation.

\subsection{Results and analysis}

\subsubsection{Comparison with temporal baselines}

Figure~\ref{fig:results_baselines} shows that TE gives the highest window F1 (0.6581), AUROC (0.8881), video F1 (0.7686), and event recall (0.9767). MaskedBiMamba gives the highest window precision (0.6048) and the lowest false-alarm rate (198.5 per evaluated hour), with video F1 0.7632. These results show a trade-off between recall and the reliability of positive predictions: TE detects more fall windows, while MaskedBiMamba produces fewer unmatched event predictions.

\subsubsection{Le2i baseline comparison}

Figure~\ref{fig:results_baselines} compares the three baseline architectures on Le2i. TE gives the highest window F1 and AUROC. TCNTE gives the highest video F1, increasing it from TE's 0.8533 to 0.8768, while reducing false alarms from 158.1 to 118.4 per evaluated hour. The change in model ranking between window and video metrics reflects the effect of temporal aggregation.



\subsubsection{Ablation study}

We evaluate ten MaskedBiMamba variants over the same four folds and three seeds (Figure~\ref{fig:results_ablation}). Removing bidirectionality reduces window F1 from 0.6395 to 0.6236; removing temporal attention reduces it to 0.6230. Both variants also reduce video F1 and increase false alarms. Thus, attention and bidirectional processing contribute to both local classification and event aggregation in this comparison.

The other components show a mixed effect. Removing frame masking gives the highest clean window F1 (0.6516), while removing quality pooling gives the highest video F1 (0.7729). Removing confidence input increases false alarms from 198.5 to 222.0 per hour. Mask ratios 0.05, 0.20, and 0.30 produce fewer false alarms than 0.15, whereas 0.10 gives more. The model's operating point therefore depends on how masking and quality weighting balance sensitivity against false positives.

\subsubsection{Robustness to missing observations}

We perturb the resampled poses before normalization. Joint and frame removal independently set observations to zero with probabilities 0.1, 0.2, and 0.3; frame removal also clears the corresponding box features. Time positions are retained. Confidence noise adds Gaussian noise with standard deviation 0.1, 0.2, or 0.3 and clips the result to $[0,1]$. A further condition removes every lower-body joint. Figure~\ref{fig:results_robustness} reports all evaluated levels of each perturbation for MaskedBiMamba and TCNTE. At frame-drop probability 0.30, MaskedBiMamba retains window F1 0.6276, compared with 0.4361 for TCNTE. Their clean scores in this evaluation are 0.6395 and 0.6255, respectively. Both models deteriorate under random joint removal and complete lower-body loss. The larger performance loss from removing joints suggests that temporal context compensates more readily for missing observations across time than for persistent loss of body geometry.

\subsubsection{Cross-dataset evaluation}

We apply the trained MaskedBiMamba and TCNTE models to all 12,650 Le2i windows (Figure~\ref{fig:results_robustness}). TCNTE gives higher clean window F1, 0.4950 versus 0.4687, while their video F1 values are close: 0.8307 and 0.8299. At frame-drop probability 0.30, MaskedBiMamba retains window F1 0.4507 and video F1 0.8243, compared with TCNTE's 0.2782 and 0.8126.

Le2i contains 130 positive and 60 negative videos under the evaluation labels. An all-positive video classifier therefore has F1 $260/(260+60)=0.8125$. Clean video specificity is 0.1958 for MaskedBiMamba and 0.1736 for TCNTE. The high proportion of fall videos and max pooling in Eq.~\eqref{eq:metric_video} raise video F1 here, while window F1 and video specificity give a more complete view of cross-dataset performance.



\subsubsection{Offline edge deployment}
Figure~\ref{fig:pi_results} summarizes hardware measurements. The Hailo pipeline processes $20.56\pm0.39$ frames/s, compared with $1.73\pm0.02$ frames/s for CPU ONNX, an 11.9-fold throughput increase. The mean per-replay median pose latency falls from $527.1\pm2.5$ to $37.6\pm0.4$ ms. Local MaskedBiMamba inference takes approximately 7.7 ms per window with the Hailo pipeline. These throughput measurements include video decoding, pose processing, window classification, and local record writes, but exclude model initialization.

On the 40 synthetic clips, all 20 fall clips have a positive prediction, while eight of the 20 non-fall clips are false positives. One non-fall clip yields no valid pose window. Coverage is 39/40 (97.5\%), accuracy among classified clips is 31/39 (79.49\%), and F1 is 0.8333. Valid body poses occur in 3,154 of 3,240 frames, producing 663 classified windows and durable records. The eight false positives include two sitting and two standing-up clips. Only 14 of the 20 positive clips produce a positive window ending inside the annotated fall interval; five of the six misses have intervals ending before the one-second input window is available. Clip-level recall therefore differs from detection during the annotated event.

A 603.8-second isolated replay processes 11,016 frames and writes 2,312 records without interruption. CPU temperature reaches 57.85\,$^\circ$C with no reported throttling; peak process memory is 150.53 MiB. Killing the record writer preserves all 100 confirmed writes and the corresponding alert states on restart.

Six integration tests cover local storage and batch synchronization. On the deployed cloud, 34 queued records survive a withheld acknowledgement and service restart without duplicate insertion. Figure~\ref{fig:cloud_recovery} shows delivery after a 30-second upload-path outage and the receipt-time distribution during connected operation. The 17 retained records are delivered, and the queue is observed empty 2.83 seconds after recovery. All 85 records across the delivery tests match their edge identifiers and capture timestamps. Connected operation has a median receipt time of 1.45 seconds over 34 records (95th percentile 2.69 seconds). These measurements support recovery of the event history after interrupted connectivity. A separate USB-camera test confirms disconnected acquisition; full-body framing is required before that camera can classify.
