\subsection{Offline inference and hardware acceleration}

The implementation reuses Ultralytics pose estimation~\cite{ultralyticsPose}, HailoRT, and Mamba operators~\cite{gu2023mamba}; TCNTE~\cite{yu2025tcnte} is a comparison baseline. FallGuard integrates quality-aware bidirectional classification with local alert storage and deferred cloud synchronization.

The repository includes model/metric code, configurations, manuscripts, aggregate results, selected temporal weights, and deployment source with generic service templates. Credentials, raw videos, and runtime databases are excluded. Exact training replay requires reconstructing the absent original training manifests and pose caches.

The runtime reads a USB camera or local video. FFmpeg preserves video timestamps. Hailo runs YOLOv8s-pose, decodes 17 COCO keypoints, and selects the highest-confidence person; 12 body joints feed the temporal model. CPU ONNX provides a pose fallback.

A timestamped buffer forms one-second windows up to five times per second, interpolates to 30 samples, and applies training normalization. The quality input uses Eq.~\eqref{eq:quality_features}. ONNX Runtime executes MaskedBiMamba on the Pi CPU. Separate camera acquisition avoids accumulating stale frames.

\subsection{Record storage and synchronization}

SQLite commits each prediction and alert state together. The independent private outbox exposes pending records. Cloud import deduplicates identifiers and preserves observation times. Delivery is acknowledged only after the cloud transaction commits; retry drains pending batches after reconnection.

\subsection{Detection interface}

The local and cloud workspaces provide overview, history, and diagnostics. The Pi page reads existing preview/status/SQLite without a second inference pipeline. It includes a 120-window chart, state/time/delivery filters, pagination, CSV, and temperature/memory/disk/load readings, all accessible locally without networking.

The cloud queries its durable archive and reads current Pi status/preview through a token-protected private bridge. Invalid poses, expired predictions, or edge loss clear current probability; unavailable pending counts are unknown. Same-origin JSON and a page token protect controls. Pausing preserves history and the outbox.

The 7 October 2026 deployment check verified edge version 2026.10.07 and cloud version 2026.10.07-cloud. The update retained 3,304 windows and 306 event rows, with zero pending records: operational counts, not evaluation samples. Twenty-one temporary-fixture backend/integration tests and both actual page-script checks passed. They establish interface and delivery behavior, not accuracy.
