\begin{abstract}
This project proposes a single-camera fall-detection system for indoor assisted-living scenarios. A Raspberry Pi~5 with AI HAT+~2 performs real-time human pose estimation and transmits only skeletal, motion, quality, and timing features to a cloud backend through MQTT/TLS. The cloud service applies temporal fall classification, pose-quality-aware feature fusion, a multi-stage alert mechanism, event storage, and dashboard visualization. The system will be evaluated using subject-independent experiments, controlled ablations, visual-degradation tests, cross-dataset evaluation, and end-to-end latency measurements.
\end{abstract}
